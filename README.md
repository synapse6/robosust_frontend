# RoboSUST Frontend

A modern Next.js landing page for RoboSUST, showcasing the club’s workshops, projects, achievements, events, and blog content.

## Overview

This project is built with Next.js and Tailwind CSS to create a polished, responsive, and visually rich frontend for the RoboSUST community.

### Included sections

- Hero section
- About section
- Events section
- Projects section
- Achievements section
- Blog section
- Footer and navigation

## Tech Stack

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
- Lucide React

## Prerequisites

Make sure you have the following installed on your machine:

- Node.js 18 or newer
- npm or yarn

## Installation

```bash
npm install
```

## Run Locally

Development server:

```bash
npm run dev
```

Then open:

```bash
http://localhost:3000
```

Production build:

```bash
npm run build
npm run start
```

## Scripts

```bash
npm run dev     # Start the development server
npm run build   # Build the app for production
npm run start   # Start the production server
```

## Deployment

This project is configured for deployment with Vercel. The repository also includes a `vercel.json` configuration.
